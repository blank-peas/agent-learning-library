# AI Agent 开发工程师面经 QA 冲刺

这不是知识库全文的替代品，而是一套按面试模块收敛的回答骨架。每题先用 30–60 秒答清结论、取舍和落地，再按追问展开项目细节。

## 使用方法

1. 先看题目，脱稿说出结论。
2. 对照答案补齐“为什么、怎么做、如何验证”。
3. 每题替换一个项目里的真实参数、失败案例或指标；没有做过的内容不要编造。

## 面试回答通用公式

> **先给结论** → **说约束与取舍** → **给实现路径** → **用指标或失败案例验证**。

例如，不要只答“我们用了 RAG”；应答“知识频繁变化且需要引用，所以先用 RAG 而非微调。链路是解析、按语义切分、混合召回和 rerank；我用 Recall@K 与引用正确率监控，并将低置信度请求降级为澄清或拒答。”

题目由本项目已收录的公开牛客实录和通用面经归纳而来，重点覆盖近期出现的 Context Engineering、Harness、A2A、Skills、AI Coding 与工程质量追问。公司与候选人的真实项目细节只用作学习线索，不作为可照搬的答案。
