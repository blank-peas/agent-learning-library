# 来源、许可与使用边界

本阅读库的「原始资料镜像」是为个人本地学习制作的结构化副本。每个资料库都保留其来源链接、仓库名、作者信息（若原仓库提供）与许可证文件。

## 已明确许可的资料

- `ai-handbook`：仓库附带 Apache-2.0 许可证。
- `Hello-Agents`：仓库附带 CC BY-NC-SA 4.0 许可证；应保留署名，并且不能用于商业用途，衍生内容需以相同方式许可。

## 未发现顶层许可证的资料

`agent-camp`、`agent-interview-100`、`agent-interview-hub` 和 `ai-agents-from-zero` 当前克隆版本没有顶层许可证文件。它们可在这台机器上作为学习参考资料保留，但**不应把镜像站直接部署、出售或再次分发**。若要公开发布，需要取得作者许可或仅保留链接与自行撰写的摘要。

`ai-agent-interview-guide` 附带 MIT 许可证；但其 README 还写有学习参考、避免商业用途的提示。公开使用前应同时尊重该提示与其中引用的第三方材料。

## 关于面经与第三方材料

仓库中的公司面试题、截图、外链或代码样例，可能还有各自的使用限制。即使仓库有开源许可证，也不自动改变第三方材料的权利归属。

本页不是法律意见；它的作用是让本地整理在使用和发布时不丢失来源与边界。
