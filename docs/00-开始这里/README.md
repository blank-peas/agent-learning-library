# Agent 学习书架

这是一本按能力递进编排的**本地 Agent 学习书**，不是一份把资料按 GitHub 仓库堆放的索引页。

从左侧第一章顺序往下读即可：模型与 Prompt → Agent 原理 → RAG → 工具/MCP → 编排 → 上下文 → TS 工程化 → 评测安全 → Coding Agent → 项目与面试。不同仓库的正文已放进相应章节；右侧始终显示当前文章的小目录。

## 怎么读

1. 先读本章导读，明确目标与最小交付物。
2. 再按左侧文章顺序阅读；内容虽来自不同开源教程，但已归到同一个能力主题。
3. 每一章做一个最小练习；不要只刷概念或面试题。

## 编排原则

- 不按来源仓库展示，统一按学习主题展示。
- 每篇保留完整正文、示例与来源标记，方便追溯。
- 面试题被放在最后一章，避免打断前面的工程学习。

> 本站只在本机运行。原始内容不被移除作者署名或许可证；公开部署前请先阅读下一页的使用边界。
