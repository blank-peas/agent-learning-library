# 第 5–6 周：ReAct、记忆与上下文

## 要解决的问题

Agent 的价值是一个能被控制和观察的循环，不是“无限调用模型”。学习 ReAct、Plan-and-Execute 与多 Agent 前，先规定停止条件、工具预算、上下文预算和人工接管点。

## 本周交付

实现一个只允许三轮工具调用的研究助手。界面展示计划、工具调用、证据和最终答案；超时或低置信度时请求用户确认。
