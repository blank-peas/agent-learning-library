# 第 1–2 周：模型、提示与结构化输出

## 要解决的问题

LLM 是概率模型，不是稳定的 JSON API。先掌握提示边界、流式响应、结构化输出与失败处理，才能把它接进前端产品。

## 本周交付

用 TypeScript 做一个流式「需求澄清助手」：输入用户需求，输出符合 Zod Schema 的任务卡；当输出不合法时显示重试原因，而不是把原始异常丢给用户。

## 阅读顺序

1. `ai-handbook` 中模型基础、Prompt 与 Agent 基础部分。
2. `Hello-Agents` 的入门章节和案例。
3. 进入原始资料时优先保留作者的章节顺序；这里仅规定你的工程练习顺序。
