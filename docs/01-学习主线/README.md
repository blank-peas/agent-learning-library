# 12 周：从前端到 Agent 工程师

目标不是把框架名背下来，而是形成一条完整的工程闭环：**模型输出 → 检索/工具 → Agent 运行时 → 前端体验 → 评测、安全、可观测 → 作品集**。

| 阶段 | 周数 | 你最终要能交付 |
| --- | --- | --- |
| 基础 | 1–2 | 一个有结构化输出与流式状态的模型交互页 |
| 能力接入 | 3–4 | 带检索、工具调用和 MCP 边界的应用 |
| Agent 运行时 | 5–6 | 可控的 ReAct 循环与上下文策略 |
| 产品化 | 7–8 | 有权限、确认、失败态和可观测性的 TS 产品 |
| 可靠性 | 9–10 | 有测试集、评测、追踪与安全保护的 Coding Agent |
| 求职闭环 | 11–12 | 可演示项目、架构说明与面试复盘材料 |

下一页从第一阶段开始；每阶段都链接到完整原文资料，而不是替代它们。
