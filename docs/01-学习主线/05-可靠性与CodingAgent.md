# 第 9–10 周：评测、安全与 Coding Agent

## 要解决的问题

“看起来能用”不能证明 Agent 可靠。把成功标准变成测试集、指标、trace 和回归测试，才有资格讨论优化模型或 prompt。

## 本周交付

为研究助手定义 20 条任务集，分别记录正确性、引用覆盖率、工具成功率、耗时和成本；再用同一套思路实现受限沙箱中的 Coding Agent。

## 安全底线

- 不把网页、检索结果或工具输出天然视为可信指令。
- 高风险动作采用 allowlist、最小权限与人工确认。
- 工具返回内容与系统指令隔离，防 Prompt Injection。
