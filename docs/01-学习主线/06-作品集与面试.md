# 第 11–12 周：作品集与面试

## 作品集应当呈现什么

选择一个真实但范围可控的场景（知识库、代码审查、数据分析或内部流程）。README 要能回答：问题、架构、工具权限、评测结果、失败案例、成本与下一步。

## 面试复盘顺序

1. 先能解释 RAG、Tool Calling、ReAct、MCP、Context 的边界。
2. 再能基于自己的项目讨论安全、评测和取舍。
3. 最后用题库查漏，而不是用题库代替做项目。

原始面试资料位于左侧「原始资料镜像」。其中的观点和题目归原作者；把它们转成你自己的项目复盘，才是最有效的准备。
