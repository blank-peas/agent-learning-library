# 第 3–4 周：RAG、工具与 MCP

## 要解决的问题

知识从哪里来，动作由谁执行，权限如何收口？RAG 解决可检索知识，Tool Calling 解决受控动作，MCP 解决工具互联；三者不应混为一个概念。

## 本周交付

完成一个团队知识助手：文本入库、检索与引用展示；再接入一个只读 MCP 工具。写下工具的输入 Schema、权限和失败策略。

## 阅读重点

- RAG 的分块、召回、重排、引用与评测。
- Function Calling 的参数校验、幂等、确认和审计。
- MCP 的客户端/服务端边界与最小权限。

## 自测

- 什么时候 RAG 比长上下文更合适？
- 一个工具为什么必须有输入校验、超时和审计？
- MCP 是模型协议还是工具互操作协议？
