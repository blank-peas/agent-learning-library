# 第 7–8 周：TS 产品化与工程化

## 要解决的问题

前端 Agent 开发的核心不是“让浏览器调用模型”，而是把用户体验和服务端受控执行连接起来：流式状态、审批、恢复、权限、错误态、追踪链接。

## 本周交付

把前六周应用收敛为 BFF + React/Next 前端。所有密钥与高权限工具在服务端；前端以事件流渲染每一步状态，提供取消、重试与确认动作。

## 工程检查

- Zod 或等价 Schema 同时用于工具参数和 UI 状态。
- 长任务有 task id、取消和恢复语义。
- 工具写操作有显式用户确认。
- Trace ID 从服务端贯穿到前端。
